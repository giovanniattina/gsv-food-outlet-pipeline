# Pipeline: S02 + U02 + OCR Fusion

Inference script that classifies Google Street View panoramas into **healthy** or **unhealthy** food purchasing places using three sequential stages:

1. **S02** (Stage 1) — DINOv2-Large + MLP binary classifier: commercial vs non-commercial.
2. **U02** (Stage 2B) — DINOv2-Large + MLP binary classifier: healthy (g0/g1g2) vs unhealthy (g3/g4).
3. **Stage 3B OCR** — PaddleOCR → keyword matching (Jaro-Winkler) → binary probability scoring → weighted-average fusion with U02.

Non-commercial images (S02 → `non_commercial`) are skipped: they receive no U02 or OCR inference.

```bash
pip install paddlepaddle-gpu

```

## Obtaining the Model Checkpoints

The `.pt` checkpoints are generated by re-running the Stage 1 and Stage 2B ablation notebooks with the `save_path` parameter. The expected paths are:

```
results/phase1/models/S02_dinov2-large.pt   # Stage 1 — commercial/non-commercial
results/phase1/models/U02_dinov2-large.pt   # Stage 2B — healthy/unhealthy
```

To regenerate them:

```bash
# Stage 1 — S02
marimo edit experiments/stage1_ablation/03_supervised_baseline.py
# Run the DINOv2-Large extraction cell, then the training cell.

# Stage 2B — U02
marimo edit experiments/stage2b_ablation/04_binary_baseline.py
# Run the DINOv2-Large extraction cell, then the training cell.
```

## Input Folder Structure

Images must be organized as:

```
<parent_folder>/
├── <city>/
│   ├── <location>/
│   │   ├── image1.jpg
│   │   ├── image2.jpg
│   │   └── ...
│   └── <location>/
│       └── ...
└── <city>/
    └── ...
```

Each `.jpg` is treated as an **equirectangular panorama**. The script extracts four perspective crops per panorama (headings: 0°, 90°, 180°, 270°) before classifying.

## Usage

```bash
python pipeline/run_pipeline_s02_u02.py \
    results/phase1/models/S02_dinov2-large.pt \
    results/phase1/models/U02_dinov2-large.pt \
    /path/to/parent_folder \
    output/results.csv
```

| Argument | Description |
|---|---|
| `S02_dinov2-large.pt` | Path to the Stage 1 checkpoint |
| `U02_dinov2-large.pt` | Path to the Stage 2B checkpoint |
| `parent_folder` | Root folder containing `city/location/*.jpg` |
| `output_path` | Output CSV path (parent directories are created automatically) |

## Output CSV

One row per perspective crop (4 rows per panorama). Key columns:

| Column | Description |
|---|---|
| `image_path` | Absolute path to the source panorama |
| `city` | City name (from folder structure) |
| `location` | Location name (from folder structure) |
| `panorama_heading` | Perspective heading in degrees (0, 90, 180, 270) |
| `urban_function_class` | S02 output: `0`=commercial, `1`=non_commercial |
| `vision_label` | U02-only prediction: `healthy` or `unhealthy` (or `non_commercial`) |
| `food_health_label` | Final fused label: `healthy`, `unhealthy`, or `non_commercial` |
| `ocr_decision_source` | `ocr_match`, `ocr_silent_fallback`, or `non_commercial` |
| `n_matched` | Number of OCR keyword matches |
| `matched_keywords` | List of matched keyword tokens |
| `urban_object_probs` | Final fused probabilities `[p_healthy, p_unhealthy]` |

## Configuration

Constants at the top of `run_pipeline_s02_u02.py`:

| Constant | Default | Description |
|---|---|---|
| `FUSION_ALPHA` | `0.5` | Vision branch weight: `p_final = α·p_u02 + (1-α)·p_ocr` |
| `OCR_THRESHOLD` | `0.85` | Jaro-Winkler similarity threshold for keyword matching |
| `WEIGHT_SPECIFIC` | `2.0` | Score multiplier for exact specific-indicator matches |
| `WEIGHT_GENERAL` | `1.0` | Score multiplier for general keyword matches |

## Fusion Logic

```
Image (panorama)
    └─ panorama_to_perspective_fast() ×4 headings
           └─ S02 (DINOv2-Large + MLP)
                  ├─ non_commercial → skip U02/OCR, label = "non_commercial"
                  └─ commercial
                         ├─ U02 → p_u02 = [p_healthy, p_unhealthy]
                         └─ OCR → keyword match → score_image_binary() → p_ocr
                                ├─ OCR silent (n_matched=0) → p_final = p_u02
                                └─ OCR active  → p_final = 0.5·p_u02 + 0.5·p_ocr
                                       └─ food_health_label = argmax(p_final)
```
